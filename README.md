# ChamaCore

A secure, modern, mobile-first platform for chamas, savings groups, investment clubs, and welfare organisations.

## What is included

- Next.js + TypeScript foundation
- Supabase-ready auth and database configuration
- Premium fintech design system
- Mobile-first onboarding and dashboard layout
- Role-based access patterns for group members, treasurers, chairpersons, and admins
- Server-side enforcement guidance for permissions and financial records

## Getting started

1. Install dependencies:
   npm install
2. Copy the environment variables:
   cp .env.example .env.local
3. Update the Supabase credentials with your own project values.
4. Run the app:
   npm run dev

## Project stages

- Stage 1: Foundation and secure account access
- Stage 2: Multi-group support and memberships
- Stage 3: Contribution and expense recordkeeping
- Stage 4: Meetings, payouts, voting, and operational workflows
- Stage 5: Community, analytics, AI, payment integrations, and global readiness

## Security note

Do not publish service-role keys or secret credentials in frontend code, public screenshots, or public repositories. Keep those values server-side only.
